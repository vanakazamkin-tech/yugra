## Ограничения сопоставимости

- Инвестиции включают добывающую отрасль (в районе на неё приходится основная часть вложений). Нельзя объединять их с инвестициями без добычи из рейтинга муниципалитетов.
- Индексы реальных доходов, зарплаты, розничной торговли и платных услуг показывают динамику, а не рублёвый уровень показателя.
- Регистрируемая безработица не равна общей безработице по методологии МОТ.
- Коэффициенты рождаемости, смертности и естественного прироста выражены на 1000 человек населения.
- Данные относятся к Сургутскому району и не переносятся на городской округ Сургут.

## Техническая проверка

Импорт выполнен отдельной миграцией `20261030130838_import_surgutsky_ser_2023_observations.sql`. Повторная вставка ограничена проверкой логического ключа `municipality_id + indicator_code + reference_year + reference_period`. Источник зарегистрирован в `data_sources` со статусом `partially_imported`, так как из документа извлечена только часть потенциально полезных показателей.
