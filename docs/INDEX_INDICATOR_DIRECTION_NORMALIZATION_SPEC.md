# Спецификация направления влияния, формул и нормализации индикаторов Yugra18

**Версия:** 0.1, проект для экспертной проверки  
**Дата:** 06.11.2026  
**Статус:** методологическая спецификация-кандидат; не является утверждённым реестром и не разрешает автоматически включать показатели в индекс.

## 1. Что именно нормализуется

В методике необходимо разделять три операции:

1. Приведение исходных наблюдений к сопоставимой величине — например, рубли инвестиций на человека или доля собственных доходов бюджета.
2. Проверка сопоставимости — одинаковое определение, география, период, единица, источник и знаменатель.
3. Нормализация для сравнения муниципалитетов — перевод сопоставимых значений в относительную шкалу.

Текущий расчётный модуль использует процентильное ранжирование внутри выбранного муниципального среза. Для показателя с направлением «выше — лучше»:

Score_i = 100 × (rank_i - 1) / (n - 1)

Для «ниже — лучше» направление инвертируется:

Score_i = 100 - 100 × (rank_i - 1) / (n - 1)

При совпадающих значениях используется средний ранг. При n < 5 оценка не рассчитывается. Процентиль — это относительное положение в конкретной группе и периоде, а не абсолютный уровень благополучия и не изменение во времени.

**Важно:** процентильная шкала сама по себе не исправляет плохую исходную метрику. Сначала нужно правильно построить показатель и подтвердить его сопоставимость. Выбросы диагностируются, но автоматически не удаляются.

## 2. Кандидаты: формулы и направления

Направления ниже — рабочие гипотезы. «Выше — лучше» или «ниже — лучше» должно быть утверждено экспертно с учётом северной специфики, структуры экономики, удалённости и муниципальных функций.

| Показатель / код | Формула входной метрики | Рабочее направление | Статус и ограничения |
|---|---|---|---|
| Инвестиции без добычи на человека (fixed_capital_investment_non_mining) | Инвестиции за год / среднегодовая численность населения | Не утверждать автоматически; условно выше — лучше | Номинальные рубли; нужны дефлятор/индекс физического объёма, проверка состава видов деятельности и крупных проектов. Доступны 2022–2023 |
| Инвестиции организаций без МСП (fixed_capital_investment_enterprises_non_sme) | Исходное значение / среднегодовое население — только после подтверждения единого охвата | Не определено | 11 МО в 2024, 7 в 2025; разные исходные названия и единицы тыс. руб.; нельзя объединять с предыдущим рядом |
| Субъекты МСП на 10 тыс. (sme_per_10k) | Число субъектов МСП / население × 10 000 | Условно выше — лучше | Сверить, какие субъекты входят в числитель, активность/регистрацию, дату знаменателя и два исходных названия; покрытие 6 МО |
| Доля занятых в МСП (sme_employment_share) | Численность занятых в МСП / точно определённая общая численность занятых × 100 | Не задавать без определения знаменателя | Нельзя автоматически трактовать рост доли МСП как рост устойчивости: важны качество занятости, производительность и отраслевой состав. 19 verified МО в 2022–2023, только 2 в 2024 |
| Среднесписочная численность без МСП (average_employees_annual) | Исходная среднесписочная численность / население трудоспособного возраста — только если статистически оправдано и совпадает география работников/населения | Контекст до утверждения | Абсолютная численность — масштаб, не уровень занятости жителей. Охват видов деятельности и варианты названия требуют сверки; 11 МО |
| Средняя зарплата без МСП (average_monthly_salary_annual) | Номинальная среднемесячная зарплата; для динамики — дефлятированная величина | Условно выше — лучше в одном году | Нужны охват, отраслевой состав, источник индекса цен и методика реальной зарплаты. 9 МО; нельзя напрямую сравнивать номинальный рост с инфляцией |
| Население (population_municipality) | Численность на 1 января | Контекст, не балл | Размер территории/рынка, знаменатель для производных показателей |
| Доля городского населения | Городское население / общее население × 100 | Не монотонно; контекст | Урбанизация не является безусловным благом или риском; зависит от расселения, доступности и структуры муниципалитета |
| Доля собственных доходов бюджета (производная) | Доходы без безвозмездных поступлений / общие доходы × 100 | Условно выше — лучше | Кандидат финансовой самостоятельности; Q3 2024 и 2025, по 22 МО; нужно утвердить точное бюджетное определение и единый срез |
| Доля трансфертов (производная) | Межбюджетные трансферты / общие доходы × 100 | Условно ниже — лучше, не самостоятельный дублирующий балл | Есть покрытие 22 МО за 2025-Q3; почти зеркальна доле собственных доходов в аддитивной декомпозиции, поэтому нельзя включать обе как независимые равновесные метрики |
| budget_tax_non_tax_revenue | Не задавать производную до получения официального определения | Не определено | Не синоним budget_revenue_excluding_grants; различается во всех 22 МО в 2025-Q3 |

## 3. Формулы знаменателей и временные базы

### 3.1. Инвестиции на человека

Предпочтительная база — среднегодовое население, если первоисточник не предписывает иной знаменатель:

Среднегодовое население_t = (Население на 01.01.t + Население на 01.01.(t+1)) / 2

Инвестиции на человека_t = Инвестиции_t / Среднегодовое население_t

Перед расчётом необходимо:
- убедиться, что инвестиции и население относятся к одной муниципальной территории;
- сверить, включены ли инвестиции организаций, филиалов и обособленных подразделений по месту деятельности или регистрации;
- подтвердить, что исключение добывающего сектора одинаково для всех МО;
- перевести единицы в рубли до деления;
- получить официальный индекс физического объёма инвестиций либо обоснованный дефлятор для межгодовой динамики.

Нельзя смешивать 2022–2023 ряд «без добычи» с рядом организаций без МСП за 2024–2025: это не доказанная временная преемственность. Для межмуниципального сравнения одного года номинальная цена частично общая, но региональные различия в структуре проектов и стоимости работ остаются.

### 3.2. Показатели МСП

Для показателя «на 10 тыс. жителей» формула допустима только при известном числителе и согласованной дате населения:

Субъекты МСП на 10 тыс. = Число субъектов МСП / Население на согласованную дату × 10 000

Проверить:
- учитываются ли юридические лица и ИП;
- включены ли только действующие субъекты Единого реестра МСП;
- берётся ли число на 10 тыс. постоянного населения или трудоспособного населения;
- совпадает ли муниципальная привязка с местом регистрации или фактической деятельности;
- не менялась ли методика между годами.

Для доли занятых МСП нельзя утверждать знаменатель по одному названию поля. Нужна таблица первоисточника, определение занятых, охват микропредприятий и ИП, а также географический принцип учёта. До этого показатель исключён.

### 3.3. Зарплата и занятость

Номинальную зарплату следует хранить отдельно от реальной. Для временной динамики:

Реальная зарплата_t = Номинальная зарплата_t / (ИПЦ_t / 100)

ИПЦ должен быть приведён к согласованной базе и соответствовать территории/периоду. Если доступен официальный индекс реальной заработной платы, предпочтительно использовать его методологически согласованную серию.

Среднесписочная численность работников без МСП — показатель рабочих мест в обследуемом круге организаций, а не доля занятых жителей. Не использовать его в виде «занятые / население» без доказательства территориальной привязки работников к месту проживания.

Квартальные значения БД ПМО могут быть нарастающими с начала года (3/6/9/12 месяцев). В схеме данных период нужно различать, например: ytd_3m, ytd_6m, ytd_9m, annual_12m. Их нельзя складывать между собой или считать независимыми кварталами.

### 3.4. Финансовая самостоятельность

Для одного и того же муниципалитета, года и периода:

Доля доходов без безвозмездных поступлений = revenue_excluding_grants / total_revenue × 100

Доля межбюджетных трансфертов = intergovernmental_transfers / total_revenue × 100

Перед применением проверить тождество бюджетной декомпозиции в первоисточнике. В проверенном срезе 2025-Q3:

Доходы без безвозмездных поступлений + межбюджетные трансферты = общие доходы

Если тождество подтверждено, две доли взаимозависимы (их сумма 100%); включение обеих в один финансовый балл создаст двойной вес одного аспекта. Предпочтительно оставить одну метрику финансовой самостоятельности либо построить отдельную многомерную финансовую конструкцию после экспертного решения.

Q3 бюджета — исполнение за 9 месяцев/нарастающим итогом; нельзя сравнивать с годовым итогом или интерпретировать как годовой бюджет.

## 4. Демография: показатели с осторожной интерпретацией

При получении муниципальных рядов Росстата рассматривать:

Естественный прирост на 1 000 = (родившиеся − умершие) / среднегодовое население × 1 000

Миграционный прирост на 1 000 = (прибывшие − выбывшие) / среднегодовое население × 1 000

Оба показателя могут иметь направление «выше — лучше» как рабочую гипотезу, но необходимо отдельно учитывать малые числа, возрастную структуру, вахтовую миграцию, маятниковые перемещения и межмуниципальное обслуживание. Для малых муниципалитетов полезно показывать абсолютные числа рядом с коэффициентом и многолетнее среднее, но не смешивать годы в одной peer-группе.

Общий коэффициент смертности не следует напрямую считать чистым показателем качества медицины: он существенно зависит от возрастной структуры. Рождаемость также не имеет универсального линейного направления влияния на устойчивость.

Коэффициент демографической нагрузки должен иметь явно зафиксированные возрастные границы и формулу (например, население младше и старше трудоспособного возраста / население трудоспособного возраста × 100). Возрастные границы должны соответствовать официальной методике конкретного ряда и периоду.

## 5. Социальная сфера: первые вычислимые производные

| Показатель | Формула | Направление | Оговорки |
|---|---|---|---|
| Обеспеченность местами в дошкольных организациях | Число мест / численность детей согласованной возрастной группы × 1 000 | Условно выше — лучше до достаточного уровня | Избыточная мощность не обязательно улучшает устойчивость; учитывать доступность по населённым пунктам |
| Нагрузка дошкольных мест | Число воспитанников / число мест × 100 | Не монотонно; оптимальный диапазон | Высокая загрузка может означать дефицит, низкая — недоступность/демографический спад; не применять линейный процентиль без целевого диапазона |
| Медицинские работники на 10 тыс. | Врачи или средний медперсонал / население × 10 000 | Условно выше — лучше | Проверить физическое место работы, ставки/физлица, филиалы, вахтовый персонал и доступность |
| Доля благоустроенного жилья | Площадь жилья со всеми определёнными видами благоустройства / общая площадь жилых помещений × 100 | Выше — лучше | Нужна единая дефиниция полного благоустройства и единица площади |
| Доля коммунальных сетей, нуждающихся в замене | Протяжённость сетей, требующих замены / общая протяжённость учитываемых сетей × 100 | Ниже — лучше | Раздельно по теплу, воде и канализации; одинаковая методика, двухтрубное исчисление для тепловых сетей |
| Доля дорог с твёрдым покрытием | Протяжённость дорог с твёрдым покрытием / общая протяжённость местных дорог × 100 | Условно выше — лучше | Не заменяет нормативное состояние; проверить, что числитель — подмножество того же перечня дорог |
| Доля дорог в нормативном состоянии | Протяжённость дорог, соответствующих нормативам / общая учитываемая протяжённость × 100 | Выше — лучше | Предпочтительнее покрытия, если методика и муниципальная собственность сопоставимы |

Не включать в индекс число школ, больниц, детсадов, километры сетей и дорог в абсолютном выражении без знаменателя/показателя качества: это в первую очередь масштаб и география.

## 6. Правила нормализации и устойчивости

### 6.1. Основной метод на первом этапе

Сохранить процентильную нормализацию, реализованную в resilienceIndex.js, как прозрачный способ ранжирования внутри одного среза. Она устойчива к единицам измерения и масштабу, но:
- зависит от состава peer-группы;
- не отражает абсолютный порог достаточности;
- может усиливать малые различия при близких значениях;
- не годится для не монотонных показателей без отдельной целевой функции.

Для каждого балла обязательно сохранять исходное значение, единицу, знаменатель, формулу производной, n peer-группы и список сравниваемых МО.

### 6.2. Выбросы и асимметричные распределения

Для инвестиций, бюджетов и иных сильно асимметричных величин дополнительно показывать:
- медиану, квартильный размах и диапазон;
- флаг IQR 1,5;
- при необходимости — логарифмированное значение как аналитическую проверку чувствительности.

Не применять логарифмирование или winsorization скрыто: преобразование должно быть указано в реестре и сохранять исходное значение. Отрицательные значения для логарифма недопустимы; для нулей нужен отдельно утверждённый подход. Автоматическое удаление выбросов запрещено.

### 6.3. Не монотонные показатели

Для нагрузки мест, урбанизации и других показателей с оптимальным диапазоном обычный процентиль «выше — лучше» не применяется. Возможные варианты после экспертного утверждения:
- отклонение от целевого диапазона;
- кусочно-линейная функция полезности с плато;
- отдельная диагностическая метрика без включения в интегральный индекс.

До утверждения функции такие показатели имеют статус context и не получают балл.

### 6.4. Внутрипилларное агрегирование

Текущая равная доля индикаторов внутри направления — техническое допущение, не экспертно утверждённая система весов. До накопления обоснования не следует включать много почти дублирующих показателей. Для каждого направления нужна проверка корреляций, математических тождеств и концептуального пересечения. В частности, доли собственных доходов и трансфертов не должны одновременно удваивать один аспект финансовой автономии.

## 7. Обязательные поля машинно-читаемой дефиниции

Каждый показатель должен быть описан записью следующего состава:

| Поле | Смысл |
|---|---|
| code | Стабильный внутренний код |
| canonicalName | Каноническое название |
| acceptedNames | Точные исходные названия, документально признанные алиасами |
| pillar | Одно из шести направлений |
| status | candidate / context / limited_candidate / not_ready |
| sourceForm | Форма/таблица/лист/раздел первоисточника |
| sourceDefinition | Официальное определение и охват |
| numerator, denominator | Состав производной метрики |
| unit | Единица результата и правила конвертации |
| periodRule | annual / ytd_3m / ytd_6m / ytd_9m / ytd_12m / point_in_time |
| geographyRule | Принцип отнесения значения к муниципалитету |
| direction | higher / lower / target_range / context |
| transformation | none / per_capita / rate_per_1000 / share_percent / deflated / log_sensitivity |
| normalization | percentile_midrank_v1 либо отдельная утверждённая функция |
| minPeers | Технический порог; текущий минимум 5 |
| limitations | Обязательные оговорки и риски двойного счёта |
| approval | Статус, дата, роль/эксперт, версия решения |

Пока нет проверенного sourceDefinition, acceptedNames, periodRule, geographyRule и знаменателя, дефиниция не может иметь статус approved и не должна передаваться в расчётный модуль.

## 8. Что остаётся заблокированным

1. Не утверждены алиасы исходных названий для неоднородных кодов.
2. Не подтверждены точные числители и знаменатели доли занятых МСП и МСП на 10 тыс.
3. Не получен дефлятор/официальная реальная серия для инвестиционной динамики.
4. Не подтверждены источником границы и охват инвестиций организаций без МСП.
5. Не собраны муниципальные ряды демографии, социальной сферы и инфраструктуры по всем 22 МО.
6. Не утверждены внутрипилларные веса и целевые функции не монотонных индикаторов.

**Решение:** этот документ фиксирует рабочие формулы и границы применимости. Он не меняет веса направлений 0,20/0,20/0,15/0,15/0,15/0,15, не утверждает новые исходные данные и не разрешает публиковать полный индекс до закрытия всех шести направлений и экспертного утверждения реестра.
