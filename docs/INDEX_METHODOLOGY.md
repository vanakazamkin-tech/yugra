# Методология интегрального индекса социально-экономической устойчивости муниципалитетов Югры

**Статус:** проект методики для технической проверки и последующего экспертного утверждения. Это не утверждённая официальная методика и не публикация официального рейтинга.

## 1. Фиксированная структура и веса

| Направление | Вес |
|---|---:|
| Экономика | 0,20 |
| Труд | 0,20 |
| Демография | 0,15 |
| Финансы | 0,15 |
| Социальная сфера | 0,15 |
| Инфраструктура | 0,15 |
| **Итого** | **1,00** |

Веса не меняются в зависимости от покрытия. Если направление не обеспечено сопоставимыми данными, полный индекс муниципалитета не публикуется. Нельзя перераспределять его вес на доступные направления: это меняло бы смысл итоговой оценки между территориями.

## 2. Допуск наблюдений

Для расчёта допускаются только строки, одновременно удовлетворяющие условиям:
- `verification_status = 'verified'`;
- `geographic_level = 'municipality'`;
- одинаковые выбранные `reference_year` и `reference_period`;
- числовое значение и непустая единица измерения;
- показатель включён в явный версионируемый реестр методики с направлением влияния и принадлежностью к одному из шести направлений.

Поселенческие, региональные, демонстрационные и `needs_review` записи не участвуют. Наличие официального источника само по себе не заменяет проверку определения, географии, периода и единицы измерения.

## 3. Сопоставимость и дубликаты

Сравнение проводится только внутри группы `indicator_code + reference_year + reference_period + unit`. Нельзя смешивать годовой итог с кварталом, накопительный итог с кварталом, разные единицы или разные определения показателя. Год и период задаются явно; автоматический выбор «последнего доступного» периода запрещён. Строка без `reference_period` не считается годовой автоматически: она исключается из любого расчёта, пока период не установлен из источника. Если один и тот же код показателя в выбранном срезе встречается в нескольких единицах измерения, все его группы исключаются до унификации единиц; отдельное ранжирование каждой единичной подгруппы могло бы создать несопоставимые шкалы для одного показателя.

Логический ключ наблюдения: `municipality_id + indicator_code + reference_year + reference_period`. Если в выбранном срезе у муниципалитета обнаружены несколько строк с одним ключом, все конфликтующие строки исключаются до разрешения конфликта. Выбор первой/последней строки недопустим.

Для межмуниципального ранжирования по показателю требуется не менее пяти муниципалитетов. При меньшем числе сопоставимых территорий показатель не получает балл. Порог — технический минимум для пилотного сравнения, подлежит проверке экспертами.

## 4. Нормализация

Для каждого показателя применяется процентильный ранг среди сопоставимых муниципалитетов на выбранный период. При равных значениях используется средний ранг (mid-rank), поэтому совпадающие значения получают одинаковую оценку.

- «Чем больше, тем лучше»: процентильный ранг.
- «Чем меньше, тем лучше»: 100 минус процентильный ранг.
- Шкала: 0–100; значение отражает относительное положение внутри сравниваемой группы, а не абсолютный уровень благополучия.

Процентильная нормализация снижает влияние экстремальных значений на шкалу. Выбросы дополнительно диагностируются правилом 1,5 межквартильного размаха; в диагностике фиксируются муниципалитет и исходное значение каждого наблюдения за пределами границ. Автоматическое удаление или winsorization не производится. Сначала требуется проверка первоисточника и определения. Для показателей с нормативными порогами и нелинейной полезностью процентильный метод может быть заменён только после отдельного обоснования и версионирования методики.

## 5. Агрегирование

Внутри каждого направления доступные и прошедшие сопоставимость показатели агрегируются простым средним процентильных баллов. Это временное нейтральное правило при отсутствии утверждённых весов отдельных индикаторов. Оно требует экспертной проверки, в частности на дублирование близких показателей и чрезмерное представительство отдельных тематик.

Полный интегральный индекс рассчитывается только при наличии оценки по всем шести направлениям:

`Индекс = 0,20·Экономика + 0,20·Труд + 0,15·Демография + 0,15·Финансы + 0,15·Социальная сфера + 0,15·Инфраструктура`

Если хотя бы одно направление отсутствует, интегральный индекс равен `NULL`. Частичные оценки направлений и покрытие показываются отдельно; они не маскируются под итоговый индекс. Пропуски не заменяются нулями.

## 6. Временная сопоставимость

В одном срезе используются один год и один тип периода. Годовые, квартальные и накопительные значения не объединяются. Важно: процентильный балл — поперечная относительная позиция муниципалитета среди сопоставимых территорий в конкретном периоде. Его нельзя напрямую трактовать как абсолютный рост или снижение устойчивости между годами: состав и распределение peer-группы могут измениться. Для межвременного анализа необходимо отдельно сравнивать исходные значения при неизменном определении, единице и географическом охвате либо разработать и утвердить методику с фиксированной базовой группой/границами нормализации. Если меняется методика источника, разрыв ряда документируется; пересчёт назад возможен только при наличии исходных данных.

## 7. Объяснимость и чувствительность

Для каждого балла должны быть доступны исходное значение, единица, период, первоисточник, направление влияния, процентильный балл и число сопоставимых муниципалитетов. Для направления показываются входящие показатели и их равновзвешенное агрегирование. Поле `coveragePercent` в расчётном результате означает долю уникальных утверждённых кодов показателей, по которым муниципалитет получил балл; покрытие направлений отдельно отражается через `availablePillars` и `availableWeightPercent`.

Чувствительность полного индекса проверяется методом leave-one-out:
- пересчёт индекса без каждого отдельного показателя внутри его направления;
- пересчёт без каждого направления с пропорциональной нормализацией оставшихся весов только для диагностического эксперимента;
- фиксация изменения результата и ранговой позиции.

Leave-one-out не заменяет анализ неопределённости исходных данных и не меняет опубликованный индекс.

## 8. Что запрещено интерпретировать как официальный результат

- Текущий демо-балл `municipalities.score` и исторические места рейтинга не являются рассчитанным по этой методике индексом.
- Нельзя выводить официальный рейтинг по неполному покрытию.
- Нельзя подменять наблюдения экспертными предположениями или сценарными темпами.
- Региональные значения РИА Рейтинг и городские показатели не переносятся на все муниципалитеты Югры.
- Процентильный балл — относительная оценка внутри выбранной группы и периода, не вероятность кризиса и не прогноз.

## 9. Ограничение текущего набора данных

В текущем срезе базы зафиксированы 1 445 наблюдений, из них 1 433 подтверждённых и 12 требующих проверки. Подтверждённые записи охватывают разные периоды и определения; 44 записи имеют поселенческий уровень и исключаются из муниципального индекса. Годовые ряды 2019–2025 и квартальные/накопительные срезы имеют неодинаковое покрытие. Поэтому количество строк нельзя трактовать как полноту панели, а сам факт наличия 22 муниципалитетов в справочнике не означает наличие всех шести направлений по каждому муниципалитету за один год.

Перед выпуском индекса требуется отдельный реестр утверждённых кодов показателей для шести направлений, согласованные направления влияния, контроль единиц и определений, оценка дублирования индикаторов и экспертное утверждение минимального покрытия.

## 10. Версия реализации

Функция `src/lib/resilienceIndex.js` реализует строгий технический контур: явные определения показателей, проверку статуса и географии, выбор одного периода, исключение дубликатов, минимальный peer coverage, процентильную нормализацию, фиксированные веса, запрет частичного интегрального балла и leave-one-out диагностику. Сам модуль не содержит выдуманного реестра индикаторов: такой реестр должен быть согласован и утверждён отдельно.


## 10. Спецификация формул и направлений

Рабочие формулы производных показателей, направления влияния, знаменатели, периодизация, ограничения процентильной нормализации и поля машинно-читаемой дефиниции вынесены в `INDEX_INDICATOR_DIRECTION_NORMALIZATION_SPEC.md`. Направления «выше — лучше» и «ниже — лучше» являются гипотезами до экспертного утверждения. Для не монотонных показателей стандартное процентильное ранжирование не применяется без отдельной целевой функции.



## 11. Проверка статистической устойчивости

Протокол сценариев чувствительности, метрики ранговой устойчивости и ограничения эмпирической проверки описаны в `INDEX_ROBUSTNESS_TEST_PROTOCOL.md`. В расчётный модуль добавлена диагностическая функция `compareMunicipalRankings`: корреляция Спирмена, средний сдвиг ранга и сохранение верхнего/нижнего квартиля. Она не меняет основной индекс и не создаёт автоматическую оценку «надёжности». До полного сопоставимого покрытия шести направлений реальную устойчивость рейтинга рассчитать нельзя.


## 12. Контроль пересечения и доминирования индикаторов

Аудит структурных связей, корреляций, фактического веса показателей и правил принятия решений описан в `INDEX_INDICATOR_DOMINANCE_AUDIT.md`. В расчётный модуль добавлена `analyzeIndicatorDominance`: она оценивает ранговые связи между показателями внутри направления и leave-one-out влияние на полный индекс. Диагностические флаги не означают автоматического исключения показателя.
