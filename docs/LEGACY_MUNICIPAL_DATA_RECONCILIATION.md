# Архив исходных данных муниципальных карточек

## Что было в проекте до подключения Supabase

В репозитории сохранён исходный файл `data/municipalities-detailed.json`. Он содержит 22 муниципалитета и поля:

- `group2024`, `rank2024`, `score` — группа, место и балл рейтинга;
- `investments.volumeBillion`, `investments.growthPercent` — инвестиционный объём и темп роста;
- `smeCount` — количество субъектов МСП;
- `assessmentScore` — оценка.

Файл не содержит даты исходного статистического среза, URL первичных документов, единиц измерения для каждого поля и методики расчёта. Поэтому это **архивные исходные значения интерфейса**, а не подтверждённая официальная статистика.

## Что сделано в базе

Создан каталог источников `legacy_project_municipalities_json` и таблица `public.municipality_legacy_snapshots`. В неё сохранены все 22 строки без потери исходных значений. Все записи имеют статус `unverified`. Таблица закрыта от ролей `anon` и `authenticated` политиками RLS и не заменяет собой проверенные наблюдения в `municipality_indicators`.

Исходный Git blob SHA: `7bbe10dbef9290abe2691b6a6a35f696cb29624d`.

## Результат сверки с текущей таблицей municipalities

Большинство полей совпадает. Обнаружены расхождения:

| Муниципалитет | Поля, отличающиеся от исходного JSON |
|---|---|
| Белоярский район | `score`: JSON 350, текущая таблица 100; `smeCount`: JSON 3 500, текущая таблица 7 000 |
| Советский район | JSON: инвестиции 21,0 млрд руб., рост 100%, МСП 3 900; текущая таблица: все три поля `NULL` |

Расхождения **не исправлялись автоматически**: у исходного JSON отсутствуют подтверждающие источники и дата среза. Значения сохранены отдельно, чтобы их можно было проверить и принять обоснованное решение без потери истории.

## Следующие шаги проверки

1. Найти первичные документы/методики для каждого поля и года.
2. Проверить, относятся ли инвестиции к общему объёму или конкретному виду деятельности, и определить единицу/период.
3. Уточнить определение количества субъектов МСП и дату среза.
4. Установить источник рейтинга 2024 года и методику балльной оценки.
5. После подтверждения переносить данные в нормализованные наблюдения с источником, годом, единицей, географическим уровнем и статусом проверки.

До выполнения проверки не использовать эти архивные цифры как официальные значения и не включать их в расчёт прогноза наравне с проверенными наблюдениями.
