Дата фиксации источника: 06.11.2026. Используется версия датасета от 28.09.2026.

Источник: https://tochno.st/datasets/bdmo
Основа: База данных показателей муниципальных образований Росстата.

## 1. Архивы для первого прохода

Не скачивать весь массив (страница источника сообщает примерно о 300 млн наблюдений). Начать с тематических разделов, которые могут закрыть пробелы в муниципальных паспортах:

- 8 — коммунальная сфера: https://storage.yandexcloud.net/tochno-st-catalog/Rosstat/data_bdmo_118_v20260928/by_section/data_section8_112_v20260928_section_file.zip
- 9 — инвестиции в основной капитал: https://storage.yandexcloud.net/tochno-st-catalog/Rosstat/data_bdmo_118_v20260928/by_section/data_section9_112_v20260928_section_file.zip
- 13 — местный бюджет: https://storage.yandexcloud.net/tochno-st-catalog/Rosstat/data_bdmo_118_v20260928/by_section/data_section13_112_v20260928_section_file.zip
- 34 — образование: https://storage.yandexcloud.net/tochno-st-catalog/Rosstat/data_bdmo_118_v20260928/by_section/data_section34_112_v20260928_section_file.zip
- 41 — эффективность ОМСУ: https://storage.yandexcloud.net/tochno-st-catalog/Rosstat/data_bdmo_118_v20260928/by_section/data_section41_112_v20260928_section_file.zip
- 42 — финансовая деятельность: https://storage.yandexcloud.net/tochno-st-catalog/Rosstat/data_bdmo_118_v20260928/by_section/data_section42_112_v20260928_section_file.zip

Архивы разделов могут содержать набор CSV по отдельным показателям. Распаковать архив локально, выбрать CSV, где присутствуют поля региона, муниципального образования, кода/названия показателя, года и значения. Не объединять CSV с разными единицами или определениями в одну серию.

## 2. Локальное извлечение строк Югры

Из корня репозитория выполнить:

```bash
node scripts/extract-tochno-hmao.mjs path/to/indicator.csv --out=tmp/hmao-review.json
```

Если названия заголовков отличаются от автоматически распознаваемых, передать точные названия столбцов:

```bash
node scripts/extract-tochno-hmao.mjs path/to/indicator.csv \
  --region="Регион" \
  --municipality="Муниципальное образование" \
  --indicator="Код показателя" \
  --indicator-name="Наименование показателя" \
  --year="Год" \
  --value="Значение показателя" \
  --unit="Единица измерения" \
  --period="Период наблюдения" \
  --oktmo="ОКТМО" \
  --out=tmp/hmao-review.json
```

По умолчанию CSV читается как UTF-8 с разделителем `;`. При необходимости задать `--delimiter=,`. Для ограничения лет доступны `--year-from=2020` и `--year-to=2026`.

## 3. Что делает скрипт

- оставляет только строки, где регион — ХМАО — Югра;
- сопоставляет известные названия 22 муниципалитетов с внутренними ID проекта;
- нераспознанные названия сохраняет в отчёте как `UNRESOLVED`, не пытаясь угадать ID;
- сохраняет исходные строки, код показателя, исходное значение как текст, единицу, период, ОКТМО и номер строки;
- различает подгруппы/срезы по всем исходным колонкам при поиске дубликатов;
- помечает каждую запись `REVIEW_REQUIRED`.

Скрипт **не**:
- переводит код БД ПМО в `indicator_code` проекта;
- конвертирует значения и единицы;
- агрегирует поселения в муниципальные районы;
- интерполирует пропуски;
- определяет направление влияния показателя;
- записывает данные в Supabase или меняет состав индекса.

## 4. Обязательная проверка перед включением в проект

Для каждой серии отдельно проверить:

1. исходный файл, URL, версию набора, SHA-256 и лицензионную атрибуцию;
2. регион, муниципалитет, ОКТМО, уровень МО и период действия границ;
3. точный код и определение показателя, все переменные разрезы;
4. единицу измерения, формат десятичных значений и статус факта/оценки/плана;
5. моментный или потоковый характер показателя и отчётный период;
6. число территорий, лет, пропусков, нераспознанных названий и конфликтующих дублей;
7. пересечения с уже имеющимися verified observations и возможные методологические разрывы.

После проверки подготовить отдельный diff-отчёт: новые наблюдения, точные дубликаты, конфликтующие значения, несовпадающие периоды и причины исключения. Только после этого решать, какие данные подходят для индекса, а какие должны остаться контекстными.
