# Единая система мониторинга рисков и прогнозирования

## Назначение

Модуль объединяет прежний «светофор рисков» и сценарное прогнозирование в одном рабочем пространстве. Внутри три представления: мониторинг рисков, сценарный прогноз выбранного показателя и полный реестр подтверждённых муниципальных показателей.

## Источники и фильтры

- Основной источник наблюдений — `public.municipality_indicators`, только строки со статусом `verified` и географическим уровнем `municipality`.
- Исполнение муниципальных программ добавляется в бюджетную группу только при статусе `verified`.
- Уровни `region`, `city` и `settlement` не смешиваются с муниципальными наблюдениями.
- Показатели с разными кодами, единицами или типами периодов не объединяются в один ряд.
- У каждого отображаемого значения сохраняется ссылка на источник, если она есть.

## Группы показателей

Пять основных направлений из паспорта проекта:
1. Занятость.
2. Доходы населения.
3. Местный бюджет.
4. Миграция.
5. Инвестиции.

Дополнительные группы в реестре: предпринимательство, производство и рынок, демография, инфраструктура и прочие показатели. Они не теряются и доступны через фильтр и поиск.

## Логика ранних сигналов

1. Наблюдения группируются по муниципалитету, коду показателя, единице измерения и сопоставимому типу периода.
2. Сравниваются только последние два наблюдения внутри такого ряда.
3. Для показателей, где рост обычно благоприятен, снижение более чем на 5% помечается как отрицательный сигнал. Для показателей с обратной направленностью (например, зарегистрированная безработица) сигналом считается рост более чем на 5%.
4. Миграция и демография не получают автоматическую оценку «хорошо/плохо» без содержательной интерпретации.
5. Красная зона: не менее двух отрицательных сигналов и не менее 40% отрицательных среди сопоставимых сигналов. Жёлтая: есть хотя бы один отрицательный сигнал. Зелёная: не менее трёх сопоставимых сигналов и нет отрицательных. Иначе — «недостаточно данных».

Порог ±5% и правила зон — технические настройки пилота, а не утверждённая методика и не статистическая вероятность кризиса. Они должны быть откалиброваны на достаточной истории и согласованы с заказчиком. Изменение одного показателя не доказывает причину ухудшения.

## Сценарный прогноз

- Пользователь выбирает муниципалитет, показатель и горизонт 1–3 года.
- При наличии двух сопоставимых наблюдений базовая траектория продолжает последнее относительное изменение.
- При отсутствии истории базовый темп равен нулю; интерфейс показывает, что статистической динамики для оценки нет.
- Стресс- и благоприятная траектории формируются как диапазон чувствительности вокруг базового темпа с учётом выбранного сценария и пользовательского шока.
- Это расчёт «что будет, если», а не обученная прогнозная модель и не вероятность наступления события.
- Номинальные суммы, квартальные и полугодовые периоды не должны сравниваться с несопоставимыми периодами; пропуски не заменяются нулями.

## Ограничения текущего набора

Данные распределены по 22 муниципалитетам неравномерно. В отдельных направлениях есть только единичные наблюдения, поэтому часть территорий закономерно получает статус «недостаточно данных». Миграционные ряды, полная муниципальная бюджетная панель и сопоставимые многолетние серии по инвестициям требуют дальнейшего пополнения. Региональные и городские рейтинги РИА Рейтинг остаются контекстом и не включаются в муниципальный риск-индекс.

## Что требуется для следующего этапа

- Расширить сопоставимые временные ряды по всем 22 муниципалитетам.
- Уточнить словарь направленности показателей: какие значения считаются ухудшением для каждого конкретного индикатора.
- Добавить контроль сопоставимости методик, единиц, инфляции, сезонности и структурных изменений.
- Калибровать пороги и веса на исторических данных и проверять качество сигналов ретроспективно.
- Включать факторы экспортной выручки, издержек и кадрового дефицита как явные сценарные допущения с обоснованием, величиной шока и датой начала.
- Не оценивать причинный эффект мер поддержки без подходящего дизайна оценки и контрольных данных.
