# Подготовка муниципальных рядов миграции Росстата

## Источники

- Основной источник: [База данных показателей муниципальных образований Росстата](https://rosstat.gov.ru/storage/mediabank/MUNST.htm).
- [Перечень показателей БД ПМО на 2025 год](https://60.rosstat.gov.ru/storage/mediabank/SVOD250207_1.htm) подтверждает три годовых ряда для всех типов муниципальных образований:
  - `8112021` — число прибывших;
  - `8112022` — число выбывших;
  - `8112023` — миграционный прирост.
- [Обработанный набор «Муниципальная статистика России с 2005 года»](https://tochno.st/datasets/bdmo) — вспомогательный вариант выгрузки данных, преобразованных из БД ПМО Росстата. Он не заменяет сверку с исходной базой Росстата.

## Безопасный порядок импорта

1. Скачай CSV-выгрузку из БД ПМО Росстата либо из вспомогательного набора. Для вспомогательного набора выбери раздел «31. Население» и распакуй архив.
2. Выбери файл, содержащий год, регион, муниципальное образование, значение и номер показателя в БД ПМО. Для автоматического отбора в поле номера должны присутствовать коды `8112021`, `8112022`, `8112023`.
3. Запусти staging-скрипт. По умолчанию он читает CSV с разделителем `;`. Если используешь обработанную выгрузку «Если быть точным», обязательно укажи её источник отдельно:
   ```sh
   node scripts/prepare-rosstat-migration-import.mjs ./path/to/export.csv --out=./migration-review.json
   ```
4. Если заголовки отличаются от стандартных, передай точные названия столбцов:
   ```sh
   node scripts/prepare-rosstat-migration-import.mjs ./path/to/export.csv \
     --year="Год" \
     --municipality="Муниципальное образование" \
     --value="Значение" \
     --indicator="Номер показателя в БД ПМО" \
     --region="Регион" \
     --unit="Единица измерения" \
     --out=./migration-review.json
   ```
5. Проверь `staged_rows`, `unmatched_municipality_names` и `duplicate_keys`. Скрипт намеренно не сопоставляет автоматически поселения с муниципалитетом верхнего уровня, если название не совпадает с известным названием.
6. Сверь каждую запись с исходной БД ПМО Росстата: код показателя, год, тип муниципального образования, значение и территориальные границы. Особенно внимательно проверь муниципальные преобразования и разрывы длинных рядов.
7. Только после сверки сформируй отдельную проверяемую миграцию/импорт. Не отмечай значения как `verified` только на основании успешного разбора CSV.

## Защитные ограничения

- Скрипт только создаёт локальный JSON для проверки и **не записывает данные в Supabase**.
- Все подготовленные записи получают статус `REVIEW_REQUIRED`; это метка staging-файла, а не допустимый статус в базе.
- Регион обязателен и фильтруется на ХМАО — Югру, чтобы не смешать значения из других субъектов РФ.
- Сопоставление по названию — предварительное. Неоднозначные названия, нераспознанные территории и дубликаты требуют ручной проверки.
- Ноль подготовленных строк означает, что формат/коды столбцов не совпали с ожиданиями; это не доказательство отсутствия миграционной статистики.
- По состоянию на 30.10.2026 подтверждённые муниципальные наблюдения миграции есть у 4 из 22 территорий: Сургут, Ханты-Мансийск, Ханты-Мансийский район и Нефтеюганск (всего 29 строк). Ряды неоднородны по годам, источникам и составу показателей; это не сбалансированная панель и не основание считать отсутствующие значения нулевыми.
- Обработанный набор [«Муниципальная статистика России с 2005 года»](https://tochno.st/datasets/bdmo) обновлён 28.09.2026, охватывает 2005–2026 годы и заявляет 603 показателя в 33 разделах, включая 31 «Население» и 32 «Занятость и заработная плата». Лицензия — Creative Commons BY 4.0; CSV — UTF-8 с разделителем `;`. Набор преобразован из БД ПМО Росстата и используется как вспомогательная обработанная копия. В Supabase он остаётся `identified`: строки ещё не загружены и не сверены с первоисточником.
- Сопоставление кодов перечня Росстата с кодами БД ПМО подтверждено: `2332000010001` → `8112021` (прибывшие), `2332000010002` → `8112022` (выбывшие), `2332000010003` → `8112023` (миграционный прирост). Все три показателя годовые и предусмотрены для всех типов муниципальных образований.
- Staging-скрипт принимает `--source-id` и `--source-url`, чтобы обработанная копия не записывалась под видом прямой выгрузки Росстата. Все строки остаются на ручной проверке; автоматической записи в Supabase нет.


## Отдельный источник демографических рядов — 30.10.2026

Проверена карточка [«Демографические показатели муниципальных образований России»](https://tochno.st/datasets/mun_demography), подготовленная на основе данных Росстата проектом «Если быть точным». В карточке указаны 2 284 муниципальных района/городских/муниципальных округа из 78 регионов, 31 947 наблюдений и охват 2010–2023 годов. Доступны CSV и XLSX; CSV UTF-8 с разделителем «;»; лицензия Creative Commons BY 4.0.

Показатели: численность населения на 1 января, среднегодовая численность, число родившихся и умерших, миграционный прирост, общие коэффициенты рождаемости/смертности/миграционного прироста. Набор использует гармонизированную сетку муниципалитетов с учётом исторических изменений; численность населения пересчитана методом демографического баланса от переписи 2010 года. Это не идентичный по методике экспорт текущей БД ПМО Росстата.

Источник зарегистрирован в Supabase как `tochno_mun_demography_2026` со статусом `identified`. **Ни одного наблюдения из него пока не импортировано.** Перед загрузкой проверить, входят ли ХМАО — Югра и все нужные территории в фактический файл, сверить ОКТМО/исторические границы и документировать преобразования. Не складывать этот миграционный прирост с компонентами прибытия/выбытия из другого источника без методологической проверки.

Отдельно: в карточке общей муниципальной статистики «Если быть точным» поисковый индекс и открытая страница показывают разные дату обновления и верхний год охвата (28.09.2026 / 2026 против 03.08.2026 / 2025). До получения актуального файла этот набор также остаётся `identified`.
