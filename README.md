# ЮГРА — аналитическая платформа муниципалитетов

Веб-прототип для изучения, сравнения и подготовки аналитических срезов по муниципальным образованиям ХМАО — Югры. Культурное оформление вдохновлено традиционными орнаментами ханты и манси.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Разделы интерфейса

- **Главная:** карта, каталог и единая панель фильтров (поиск, группа, тип территории, быстрые срезы, произвольные условия по любому показателю).
- **Карта Югры:** выбор муниципалитета на векторной карте или в списке.
- **Рейтинг:** сортируемая таблица с поиском, фильтрами и выгрузкой CSV.
- **Сравнение:** до 6 территорий и любой набор показателей. Столбчатая и лепестковая диаграммы, таблица с подсветкой лучшего/худшего значения, отклонение от среднего, медианы или первой территории; быстрые наборы («Топ-3», «Группа A», «Лучшие города», «Лучшие районы»); ссылка на сравнение; выгрузка CSV/Excel.
- **Отчёты:** конструктор. Выборка (свои фильтры / срез каталога / ручной выбор), показатели, сортировка, блоки отчёта (сводка, диаграмма, лидеры и отстающие, таблица, отклонения, комментарий) с включением и сменой порядка, именованные шаблоны, автосохранение черновика. Экспорт: печать/PDF, Excel, CSV, JSON.

## Структура кода

- `src/lib/metrics.js` — реестр показателей (подписи, единицы, «чем больше — лучше / чем меньше — лучше», расчётные показатели) и статистика. **Чтобы добавить показатель, добавьте объект в `METRICS`** — он появится в фильтрах, сравнении и отчётах.
- `src/lib/filters.js` — модель фильтра и быстрые срезы (`PRESETS`).
- `src/lib/exporters.js` — CSV, Excel (SpreadsheetML), JSON.
- `src/views/` — `FilterPanel`, `Compare`, `Reports`.
- Состояние сохраняется в localStorage: `yugra-compare-v2`, `yugra-report-draft-v2`, `yugra-report-templates-v2`.

## Данные и ограничения прототипа

- Муниципальные показатели находятся в `data/municipalities-detailed.json`.
- Геометрия карты находится в `src/ugraMapGeo.js`.
- Орнаменты и символика находятся в `public/images/`.
- Доступные в прототипе показатели ограничены полями встроенного JSON-набора. Это не подключение к обновляемому источнику данных. Перед официальной публикацией цифры, период наблюдения, первоисточники и методику расчёта необходимо проверить и при необходимости заменить на подтверждённые данные.
- PDF генерируется через диалог печати браузера — в нём можно выбрать «Сохранить как PDF». CSV — UTF-8 BOM, разделитель `;`, десятичная запятая. Excel-файл — XML-таблица (`.xls`): Excel может показать предупреждение о формате, это нормально.
