# ЮГРА — аналитическая платформа муниципалитетов

Веб-прототип для изучения, сравнения и подготовки аналитических срезов по муниципальным образованиям ХМАО — Югры. Культурное оформление вдохновлено традиционными орнаментами ханты и манси.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Разделы интерфейса

- **Главная:** интерактивная карта, каталог, быстрые срезы, расширенные фильтры и динамические сводные показатели.
- **Карта Югры:** выбор муниципалитета на векторной карте или через синхронизированный список.
- **Рейтинг:** сортируемая таблица с поиском, групповыми фильтрами и экспортом CSV.
- **Сравнение:** выбор 2–4 муниципалитетов, диаграмма по выбранному показателю, общая таблица метрик и выгрузка сравнения в CSV. Дополнительно есть отдельная симуляция сценария «до и после» меры поддержки; изменения в ней задаются пользователем и не представляют измеренный эффект программы.
- **Риски:** демонстрационный светофор с редактируемыми порогами, группировка территорий по зоне, обзор покрытия пяти групп показателей и отдельные пилотные сигналы из официальной статистики Сургута. Сигналы сравнивают одинаковые периоды год к году, показывают направление изменения и выгружаются в CSV с периодом и первоисточником; это не доказанная причина, вероятность кризиса или общий рейтинг устойчивости. До появления утверждённой методики цветовая зона считается только по баллу демо-набора.
- **Данные:** каталог источников, слой подтверждённых наблюдений, историческая динамика населения Сургута, выбираемый график экономических рядов за одинаковые периоды, отраслевая структура занятости по 16 секторам за I квартал, полугодие, девять месяцев и год, а также межмуниципальное сравнение официальных показателей за одинаковый период. Графики и таблицы выгружаются в CSV вместе с периодом, единицей измерения, примечаниями и URL первоисточника.
- **Официальные данные в отчёте:** в конструкторе можно отдельно включить или отключить таблицу проверенных наблюдений. Она сохраняет уровень географии, период, единицу измерения, примечание и источник и попадает в печатный PDF отдельно от демонстрационных полей рейтинга. Состояние переключателя сохраняется в шаблоне настроек.
- **Экспорт официальных данных:** в центре данных CSV выгружает текущую отфильтрованную выборку вместе с территориальным уровнем, источником, периодом, статусом проверки и примечаниями.
- **Отчёты:** конструктор документов с выбором территории/среза, показателей, сводки, диаграммы и таблицы; экспорт в PDF через печать браузера и в CSV; сохранение/загрузка настроек шаблона в локальном хранилище браузера.
- **Режим прогнозирования:** сценарии «Осторожный», «Инерционный», «Ускоренное развитие» и «Санкционный стресс», горизонты 1/3/5 лет, редактируемые темпы роста, модельный диапазон чувствительности, таблица результатов и экспорт CSV. Расчёт выполняется в браузере, кнопки отправки прогнозов в базу нет. Значения — результат задаваемых допущений, а не официальная или обученная на временных рядах модель.
- **Паспорт территории:** основные значения муниципалитета и переход к созданию отчёта по одной территории.

## Фильтры и показатели

Доступны фильтры по группе рейтинга, поисковой строке, диапазону итогового балла, минимальному объёму инвестиций, минимальному числу субъектов МСП, динамике инвестиций и оценке бизнеса. Быстрые срезы: топ-5 рейтинга, инвестиции от 50 млрд ₽, рост инвестиций от 103%, оценка бизнеса от 4,5.

В отчёт и сравнение можно включить итоговый балл, место в рейтинге, инвестиции, динамику инвестиций, число субъектов МСП и оценку бизнеса.

## Подключение Supabase

Приложение запрашивает `public.municipalities` сразу после открытия и повторяет запрос каждые 60 секунд. После успешной загрузки в шапке отображается время последней синхронизации. При ошибке соединения приложение сохраняет последние успешно загруженные значения; до первой успешной загрузки резервным источником служит `data/municipalities-detailed.json`.

1. Установите зависимости: `npm install` (в проект добавлен `@supabase/supabase-js`).
2. Скопируйте `.env.example` в `.env.local` и заполните `VITE_SUPABASE_ANON_KEY` публичным ключом проекта Supabase (`sb_publishable_...` или legacy `anon`). Ключ `service_role` / `sb_secret_...` использовать в клиентском приложении нельзя.
3. В Vercel добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в Environment Variables и заново разверните проект.
4. Убедитесь, что таблица `public.municipalities` доступна для `SELECT` через настроенную RLS-политику. Колонки соответствуют SQL-схеме: `id`, `name`, `group_2024`, `rank_2024`, `score`, `investments_volume_billion`, `investments_growth_percent`, `sme_count`, `assessment_score`.

Поля SQL преобразуются в существующую модель интерфейса, поэтому фильтры, карта, сравнение, рейтинг и отчёты продолжают использовать единый формат объектов. Это тестовое периодическое обновление раз в минуту, а не push-подписка Supabase Realtime.

## Данные, источники и ограничения прототипа

- `data/municipalities-detailed.json` — локальный резерв для каталога муниципалитетов. Часть баллов, объёмов инвестиций, динамики, количества МСП и оценок бизнеса является демонстрационной и помечена в интерфейсе.
- `public.municipality_indicators` — отдельный слой подтверждённых официальных наблюдений с источником, периодом, единицей измерения, уровнем географии и примечаниями. `public.data_sources` — каталог первоисточников и статусов импорта.
- Дополнительные официальные данные хранятся в таблицах инвестиционных площадок, муниципальных программ, цен на топливо и образовательных учреждений. Для каждого набора отдельно проверяется покрытие и дата версии.
- Реальное покрытие неполное и неоднородное: наиболее длинный текущий свежий экономический ряд — официальный паспорт Сургута за 2024–2026 годы, включая общий и отраслевой уровень занятости по 16 секторам, отгрузку продукции, перепродажу и инвестиции. Отдельные показатели доступны по Мегиону и Когалыму. Отсутствующие наблюдения не подменяются нулями; показатели города или поселения не должны автоматически трактоваться как показатели всего района.
- Открытые муниципальные источники с требованием API-ключа регистрируются в каталоге, но не считаются импортированными до фактической загрузки и проверки значений.
- Геометрия карты находится в `src/ugraMapGeo.js`; орнаменты и символика — в `public/images/`.
- Все прогнозы и светофор рисков пока концептуальны. Пороговые значения и темпы роста не являются утверждённой методикой, экспертно подтверждёнными параметрами или оценкой вероятности.
- GitHub Actions выполняет `npm run build` на каждом push в `main` и pull request, независимо от лимитов Vercel. PDF генерируется через диалог печати браузера — в нём можно выбрать «Сохранить как PDF». Экспорт CSV использует UTF-8 BOM и разделитель `;`, чтобы удобнее открываться в русской локали Excel.
