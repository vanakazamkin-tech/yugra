# ЮГРА — Земля традиций

Обновлённый интерфейс каталога муниципальных образований Югры в светлой палитре бересты, тайги и охры.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Что обновлено

- Новая шапка и навигация без пункта «О проекте».
- Прозрачный орнамент «Берёзовая ветка» на основе присланного образца — отдельные файлы в `public/images/`.
- Новый SVG-знак для бренда и favicon.
- Обновлённая композиция каталога с небольшой исторической гравюрой.
- Карточки сводных показателей, карта муниципалитетов и таблица рейтинга в едином стиле.
- Поиск, групповые фильтры, сортировка столбцов, интерактивная карта, паспорта муниципалитетов и печать в PDF сохранены.
- Адаптивная компоновка для планшетов и телефонов.

## Данные

Данные рейтинга находятся в `data/municipalities-detailed.json`, геометрия карты — в `src/ugraMapGeo.js`.
